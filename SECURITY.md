# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**[Report a vulnerability](https://github.com/kinglet-dev/kinglet.dev/security/advisories/new)**
(Security tab → "Report a vulnerability").

Please don't open a public issue for security problems.

Include what you found, how to reproduce it, and the impact you expect.

## Scope

This repository is the static website at https://kinglet.dev. Each Kinglet
tool has its own repository and its own `SECURITY.md`.

The machine-readable contact is published at
https://kinglet.dev/.well-known/security.txt (RFC 9116).
